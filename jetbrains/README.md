# VBX for JetBrains IDEs

Visual Basic X (VBX) syntax highlighting bundle for JetBrains IDEs (IntelliJ IDEA, PyCharm, CLion, WebStorm, Fleet, Android Studio, etc.).

## Installation Instructions

To enable VBX syntax highlighting in any JetBrains IDE:

1. Open **Settings** / **Preferences** (`Ctrl+Alt+S` on Windows/Linux or `Cmd+,` on macOS).
2. Navigate to **Editor** -> **TextMate Bundles**.
3. Click the **`+`** (Add) button and select the `jetbrains/VBX.tmbundle` folder.
4. Click **Apply** and **OK**.
5. Open any `.vbx` file for full syntax highlighting.
