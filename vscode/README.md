# VBX Language Support for VS Code

Syntax highlighting and snippets for
VBX (Visual Basic X) — the modern successor
to Visual Basic 6.

## Features
- Syntax highlighting for keywords,
  strings, numbers, comments, functions
- Code snippets for all constructs
- Auto-closing brackets and quotes
- Comment toggle support

## Snippets
| Prefix | Snippet          |
|--------|-----------------|
| if     | If...End If     |
| ife    | If...Else       |
| for    | For...Next      |
| wh     | While...Wend    |
| dow    | Do While...Loop |
| sc     | Select Case     |
| sub    | Sub routine     |
| fn     | Function        |
| dim    | Dim variable    |
| pr     | Print           |
| msg    | MsgBox          |
