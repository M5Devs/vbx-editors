# VBX Language Support for Micro Editor

Syntax highlighting definition for Visual Basic X (VBX) in the Micro terminal text editor.

## Installation Instructions

Copy or symlink `vbx.yaml` to your Micro syntax configuration folder (`~/.config/micro/syntax/`):

```bash
mkdir -p ~/.config/micro/syntax
cp micro/vbx.yaml ~/.config/micro/syntax/
```

When you open any `.vbx` file in Micro, syntax highlighting will automatically be enabled.
