# VBX Language Support for Notepad++

This folder contains the User Defined Language (UDL 2.1) definition file for Visual Basic X (VBX) syntax highlighting and code folding in Notepad++.

## Installation Instructions

1. Open Notepad++.
2. In the top menu bar, click on **Language** -> **User Defined Language** -> **Define your language...**.
3. In the User Defined Language dialog, click the **Import...** button.
4. Select the `vbx.xml` file located in this directory.
5. Once imported successfully, restart Notepad++ or open any `.vbx` file.
6. The syntax highlighting and code folding for VBX will automatically be applied (or select **VBX** from the bottom of the **Language** menu).
