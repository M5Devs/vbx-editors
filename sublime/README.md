# VBX Support for Sublime Text

This package adds syntax highlighting and snippets for the Visual Basic X (VBX) language in Sublime Text 3 and 4.

## Installation

1. Open Sublime Text.
2. Go to **Preferences** -> **Browse Packages...**. This opens your local `Packages` directory.
3. Open the `User` folder (`Packages/User`).
4. Copy `VBX.sublime-syntax` and `vbx.sublime-completions` into `Packages/User/`.
5. Open any `.vbx` file to enjoy VBX syntax highlighting and completions!
